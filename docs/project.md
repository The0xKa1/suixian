# 随弦

## 范围
- 本地读谱应用：谱库、平滑换页、上传音频自动对齐、实验性麦克风跟随。
- 可单独上传谱子；也可同时上传谱子和音频，或为已有谱子添加 / 替换音频。
- React、TypeScript、Vite、PDF.js；本机 Python 服务调用 Audiveris 识别谱面。
- 用户已授权本机识谱：仅谱面图像发送到 `127.0.0.1`；音频始终在浏览器解码、匹配与播放。
- 支持「重新排版 / 原件」两种阅读方式；结构化内容独立保存，重排按完整谱行分页，标题留在曲目信息区。
- Git 仓库：`github.com/The0xKa1/suixian`，主分支 `main`；服务仅监听本机，尚未线上部署。

## 当前实现
- 谱面 `#/` 与谱库 `#/library` 分开；IndexedDB 保存谱页、音符参考、原始音频 Blob 和匹配时间轴。
- PDF、多张 JPG / PNG / WebP、受支持的 MusicXML 六线谱；谱子合计 30 MB、最多 20 页。
- 音频支持浏览器可解码的 MP3 / WAV / M4A / OGG / FLAC 等，60 MB、1 秒至 8 分钟。
- MIDI 支持 `.mid` / `.midi`（SMF 0 / 1、PPQ），5 MB、8 分钟；按原始音符时间直接对齐，在本机合成统一音色 WAV，保留原始 MIDI。
- MusicXML 直接生成音符参考；PDF / 图片通过本机 OMR 提取音高与演奏顺序。
- 新上传 PDF / 图片即尝试本机解析，不依赖是否附带音频；失败保留原件并显示原因。旧 PDF / 图片可用「解析谱面」补充结构。
- 新导入保留原文件 Blob 与原页；`notation.version=1` 保存完整 MusicXML、小节 / 音符稳定 ID 和语义索引。详情见 [结构化乐谱](research/structured-score.md)。
- OpenSheetMusicDisplay 在浏览器本地重排五线谱 / TAB，随视窗宽度组行，完整系统合成阅读页，不沿用原 PDF 页眉和纸张空白。
- 原件与重排共享同一媒体播放器；音频以稳定起音 ID、拍位置和实际匹配时间重新投影，切换不重启录音。手动阅读位置亦按事件映射。
- 两种视图的选择按谱库记录保存在本机；无完整结构或重排失败时保留原件，不显示伪造谱面。MusicXML 没有原纸张图像，其保留视图称「导入版」。
- 全序列 chroma DTW 处理录音前后静音、演奏速度变化；检查整曲、每页和页首音符匹配证据。
- 不匹配、静音、缺失谱页或证据不足时拒绝生成自动翻页时间轴，保留当前谱子。
- 播放器以 `HTMLAudioElement.currentTime` 为唯一时间源；支持播放 / 暂停、跳转、翻页定位与重播。
- 进度条显示真实音频时间与匹配页界；保存后刷新、从谱库重新打开可继续使用。
- 音频模式可显示半透明竖线光标；按实际音符时间锚点移动，同一行内插值，换行 / 换页等待下一起音，暂停和拖动进度同步定位。
- 光标在同页同组谱表内保持固定顶端与高度，贯穿完整谱表组；单音 / 和弦交替不再使光标伸缩。已保存的有效坐标在播放时统一，无需重导。
- MusicXML / 示例由排版器给坐标，印刷谱从 Audiveris 原图几何取坐标，标准 TAB 使用 OCR 品位与谱行坐标；无可靠坐标时不显示光标。
- 可验证的旧 MusicXML / 示例记录自动恢复坐标；旧 PDF / 图片需重新导入。前后静音隐藏光标，界面可切换显示。
- 上传音频按真实匹配页界提前进入缓冲：默认提前 4 秒，前页下半与后页上半同时可见，页界后保留前页 2 秒再离开。
- 提前量可选关闭 / 2 / 4 / 6 秒并本地保存；短页自动缩短窗口，手动翻页直接打开整页，预览定位到真实音频时间。
- PDF / 图片 / MusicXML 使用同一音频缓冲；不把页内音乐进度当作图像行坐标。麦克风模式仍按有无可靠排版区分行级与页级跟随。
- 有光标时缓冲会收小移动范围，以保留当前谱行；优先可读性，不强求任意版式都显示各半页。
- 持续页面轨道、固定缩放与放缓的临界阻尼弹簧；新页淡入、旧页淡出，双页缓冲停留时保持清晰；支持拖动、轻扫、滚轮与键盘翻页。
- 音频缓冲进入、离开各最长 1.1 秒，起止速度与加速度平滑归零；减少动态效果时直接定位并关闭谱页淡化。
- 换谱、打开上传窗口、离开谱面、切到后台时暂停音频并清理麦克风；卸载释放音频 URL。
- 分析可取消，未完成结果不入库；写库失败会提示未保存。
- 无上传音频时仅提供「听音跟随」，不显示演示播放、自动演示进度或跨页预览；保留手动翻页，不自动开启麦克风。
- 听音跟随仅在有音符参考时可用；无参考的谱面禁用跟随并显示简短状态。
- 暖灰、点线、花括号按钮、本地许可字体、键盘操作与减少动态效果支持。

## 实际边界
- 自动识谱和音频匹配仍是实验能力，不能保证任意谱子与真实录音精确对应。
- MIDI 需配套谱子，不自动生成谱面；固定合成音色，鼓轨不播放，弯音 / 延音踏板等暂不支持。完整音符不一致或声部时序有歧义时拒绝，详见 [MIDI](research/midi.md)。
- 缓冲扩大页界附近的可见范围，不提高识谱或对齐准确率；较大偏差仍需手动翻页或调整进度。
- 原件模式仍保留 PDF 标题与空白，受旧半页缓冲限制；重排模式移除重复标题并按谱行组页。尚无手动缩放或逐页阅读区域调整。
- TAB 图片 OCR 仅有品位顺序，缺少真实时值和小节，暂不能重排；继续保留原件及原有音频对齐。手写、复杂谱面和遗漏的识谱符号仍需校对。
- 已预留小节 / 音符笔记锚点和版本结构；音符编辑器、笔记界面、编辑后的重新匹配尚未实现。
- 光标精度取决于识谱和音频对齐；缺失 / 模糊原图坐标会省略光标。当前只用于上传音频，不用于麦克风模式。
- 清晰印刷五线谱由 Audiveris 识别；具体格式和六线谱边界见 [本机识谱](research/omr.md)。
- MusicXML 当前限单乐器、含弦号 / 品位的六线谱、80 小节；重排 TAB 暂不显示时值符干，完整时值仍在 XML 中。
- 反复 / D.C. / D.S. 等未展开的演奏结构不自动推断；不处理任意跳转、移调、缺段录音。
- chroma 折叠八度，不能验证绝对八度；识谱误读、复杂复音、弱音与噪声可能造成匹配失败或误差。
- 匹配相似度不是经校准的准确率；约 40 ms 的分析帧和播放器 / 动画延迟不等同于毫秒级保证。
- 每份参考最多 2400 个音符事件，并限制动态规划矩阵大小；超限需拆分。
- 已验证控制样本和浏览器交互；尚未完成真实乐器、多设备和大规模谱面评测。
- 本机 OMR 安装脚本目前面向 macOS Apple Silicon；不提供云端识谱。
- 清除浏览器站点数据会删除谱库和保存的音频；无账号或云同步。
- PDF / OSMD 按需模块仍有超过 500 KB 的构建提示。

## 运行
```sh
npm install
npm run setup:omr  # 首次安装本机识谱引擎，本机已安装
npm run dev        # 前端 5173 + 识谱 5174
npm test
npm run test:omr
npm run build
npm run check:docs
```
- 查看：`http://127.0.0.1:5173/`；本机识谱健康检查：`http://127.0.0.1:5174/api/health`。
- 先检查进程与端口，复用健康服务；`npm run dev` 会验证并复用已有的本机识谱服务。
- 仅启动前端可用 `npm run dev:web`；仅启动识谱可用 `npm run dev:omr`。
- 当前前端与识谱服务均在运行，未发布线上。
