# 演奏跟随研究与实现

更新：2026-09-30。本页主要记录麦克风实验算法，未经真实吉他录音评测。
上传录音的离线整曲对齐见 `src/lib/audio-alignment.ts`，本机识谱见 [OMR](omr.md)。

## 论文依据
| 来源 | 原文方法 | 本项目采用与边界 |
| --- | --- | --- |
| [Dixon, DAFx 2005](https://www.dafx.de/paper-archive/2005/P_092.pdf) | 在线时间规整，将实时音频与参考录音逐帧对齐；特征强调起音。 | 借鉴增量对齐与连续路径，不要求用户提供录音；没有复现该 OLTW 算法。 |
| [Arzt、Widmer、Dixon, ECAI 2008](https://webspace.eecs.qmul.ac.uk/s.e.dixon/pub/2008/Arzt-Widmer-Dixon-ECAI-2008.pdf) | 将实时音频对齐至乐谱合成的音频，驱动物理翻页装置；论文验证使用钢琴。 | 采用“先建立谱面内部参考，再跟随现场演奏”的分工；本项目直接生成音高模板，未移植其多匹配器算法。 |
| [Nakamura 等, TASLP 2016](https://eita-nakamura.github.io/articles/TNakamura_etal_AudioScofo_ACMIEEE_TASLP_2015.pdf) | 分层 HMM、归一化 CQT、停顿与跳转状态；主要实证为单音单簧管。 | 采用局部状态滤波与停顿冻结；使用 chroma 工程替代，未实现其完整分层模型、任意跳转或吉他实证。 |
| [Henkel & Widmer, 2021](https://www.frontiersin.org/journals/computer-science/articles/10.3389/fcomp.2021.718340/full) | 训练跨模态模型，在谱图中预测音符、谱行和小节位置；主要使用钢琴数据。 | 作为后续图像路线；未移植权重，不据此声称任意吉他 PDF 可跟随。 |

原文区分了参考音频对齐、结构化谱跟随和直接谱图定位；三者不能混称为已完成识谱。
浏览器采集依据 [Web Audio API](https://www.w3.org/TR/webaudio/)，麦克风音频仅在本地内存处理。

## 输入与接口
- `ScoreReference.events` 提供按演奏顺序排列的 `{ midi, beat, durationBeats, position }`。
- `midi` 是同一起音的 MIDI 音高集合；休止不建立可匹配音符，空白时冻结。
- `position` 为从 0 开始的页码加页内进度；音频算法与翻页动画分离。
- 原创六线谱的参考来自绘制谱面的同一组弦号和品位，避免看见的谱与匹配序列不一致。
- 带弦号、品位的受支持 MusicXML 可直接建立参考，不需要第二份录音。
- PDF / 图片仍可阅读与演示；没有参考音符时不能启用听音跟随。
- `createScoreFollower(reference).process(frame)` 返回位置、事件索引、匹配指标与状态。
- `useScoreFollowing(reference)` 提供 `start / stop / seek / reset`，仅用户点击后申请麦克风。

## 音频特征
1. 读取 8192 点 PCM，约每 45–50 ms 分析一次；常用采样率为 44.1 / 48 kHz。
2. 去直流、乘 Hann 窗、基 2 FFT；窗口约 171–186 ms，会带来实际延迟。
3. 在 65–2200 Hz 寻找频谱局部峰；对数幅度抛物插值细化峰值频率。
4. `m = 69 + 12 log2(f / 440)`，按最近 MIDI 音的音高类别汇总。
5. 峰权重为 `幅度^1.5 × exp(-0.5 × (半音偏差 / 0.22)^2)`，向量做 L2 归一化。
6. 参考向量包含音高类别以及权重 0.12 的五度泛音；这是工程模板，没有训练过程。
7. RMS 上升超过 1.45 倍或相邻帧 chroma 余弦距离超过 0.24，产生起音候选。
8. 起音间隔至少 100 ms；静音阈值 RMS 0.006，未做设备自适应标定。

## 在线定位与翻页
- 只保留当前事件与下一个事件，采用向前的局部 HMM 滤波，不跨过未确认音符。
- 观测相似度 `s = cos(chroma, reference)`；观测权重 `b = exp(9 × (s - 1))`。
- 更新采用 `α_t(i) ∝ b_i(x_t) Σ_j a_ji α_(t-1)(j)`，每帧归一化。
- 仅起音后的 240 ms 开放前进；起音帧前进权重 0.82，后续帧为 0.12。
- FFT 起音混合帧可暂时不匹配；门控窗口保留，等待后续稳定证据。
- 相似度至少 0.78；后继状态权重至少 0.72；不同音高还需领先当前相似度 0.08。
- 连续 3 帧确认后输出新位置；确认事件间隔至少 100 ms，持续同音不消耗后续同音事件。
- `confidence` 是匹配指标，未经校准，不能当作统计意义的正确率。
- 安静、无关声音、错音和证据不足保持原位置，不按时钟推算页码。
- 只有确认音符位置推进，阅读器再平滑移动；动画可以缓动，不能模拟识别进度。
- `seek(position)` 重建局部起点；反复、漏音或失配后由用户校正位置。
- 时值和初始速度保留在接口中，目前不参与节拍推算或全局速度估计。

## 资源与权限
- 麦克风音频不连接扬声器、不保存或上传；上传文件则可本地播放并保存在 IndexedDB。
- PDF / 图片识谱使用已授权的本机服务，音频分析仍在浏览器完成。
- 停止、离开阅读页、换谱和卸载组件时释放 tracks、音频图、AudioContext 与动画回调。
- 权限请求尚未返回时也可取消；稍后到达的旧 stream 立即停止。
- 被新请求替代的旧权限结果不会关闭新会话；设备移除会停止会话。

## 验证
执行：`node --experimental-strip-types --test src/lib/score-following/*.test.ts`。
当前 11 项通过，包括：
- 静音、白噪声、错音、缺失音符、单帧突发与异常时间戳不误推进。
- 变速与停顿、持续同音、重新起音和手动定位。
- 44.1 / 48 kHz PCM 中 E2、A2、高音及三和弦的频谱特征区分。
- 原创谱 192 音符的五次谐波 PCM 经真实 FFT、自动起音与滤波，跨过两次页界。
- 同一首的连续拨弦波形：3 ms 起音、220 ms 衰减、800 ms 残音及跨音符 FFT 滑窗。
- 连续波形逐音到达，没有先于真实起音推进到下一个音符；页尾静音保持位置。
- 麦克风权限取消、迟到结果、交替启动、设备移除及重复清理。

测试波形是合成数据，不能替代实弹、环境噪声、设备和用户测试；未代用户启用麦克风。

## 限制与下一步
- chroma 折叠八度；相同音高类别、延音、密集扫弦与复杂复音存在歧义。
- 当前最适合清楚的单音或分解和弦；不能宣称完整吉他和弦转录。
- 没有完整 OMR、任意 PDF 音符识别、反复结构展开或自动跳音恢复。
- 局部单调路径可能在漏音后停住；这是已知边界，需要手动定位。
- 需要采集经授权的实弹测试集，评估延迟、定位误差、误翻页率与不同设备增益。
- 后续可比较 CQT / 音高显著性、扩展局部跳转与速度状态，再独立研究 TAB OMR。
